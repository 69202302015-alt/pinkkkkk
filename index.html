วิธีเปิดใช้งาน GitHub Pages

คุณสามารถนำไฟล์เว็บนี้ไปเผยแพร่บนอินเทอร์เน็ตได้ฟรีตลอดชีพผ่าน GitHub Pages โดยทำตาม 4 ขั้นตอนง่ายๆ ดังนี้:

1. บันทึกไฟล์นี้

เซฟไฟล์นี้เป็นชื่อ index.html ไว้บนเครื่องคอมพิวเตอร์ของคุณ

2. สร้าง Repository บน GitHub

ไปที่เว็บ GitHub.com กดปุ่ม New Repository ตั้งชื่อ เช่น my-portfolio และตั้งค่าเป็น Public

3. อัปโหลดไฟล์ index.html

ลากไฟล์ index.html ไปอัปโหลดใส่ Repository แล้วกด Commit changes

4. เปิดใช้งาน Pages

ไปที่เมนู Settings ➔ Pages ➔ ในส่วน Branch ให้เลือก main หรือ master แล้วกด Save

ภายใน 1-2 นาที เว็บไซต์ของคุณจะออนไลน์ที่ URL:
https://<your-username>.github.io/my-portfolio/
